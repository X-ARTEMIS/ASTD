# ASTD
Standard libraries for use in Artemis projects.

### Using ASTD
Install from the [latest release](https://github.com/X-ARTEMIS/ASTD/releases/latest) or use ```git clone github.com/X-ARTEMIS/ASTD```

Next unzip the contents (if necessary) and copy the astd directory into your working directory

Now you can include files with ```#include "astd/astd.hpp"```

# Non-important stuff from here on out (optional reading)

### Versioning System

We use semantic versioning which is major.minor.patch.

For example fixing issues would be a patch, while something larger like adding a new function to a preexisting library would be a minor update while introducing a new library would be a major update.
